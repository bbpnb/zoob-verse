## 快速观察

### 图规模

- 最大节点数：`鹿鼎记`，`3907`
- 最大边数：`天龙八部`，`6114`
- 长篇已经稳定进入 `2600+` 节点、`4700+` 边区间

### 孤点与连通性

- 孤点率整体落在 `14% - 24%`
- 最大连通分量大多在 `70% - 84%`
- 这说明当前图谱已经具备较强主干结构，但仍保留相当数量需要后处理的边缘节点

### 关系退化

- 整体集中在 `11% - 15%`
- 《越女剑》最低，为 `4.79%`
- 长篇中 `15%` 左右已经接近需要重点关注的阈值

### Token 结构

- DeepSeek 默认长篇路线 completion 占比偏高
- DeepSeek `no-thinking` 长篇 completion 占比大约降到 `30%` 左右
- Doubao 1.6 在部分长篇上 token 更友好，但不能只靠总 token 判断质量

## 当前最重要的解释方式

这张总表不应用于得出“某模型绝对更好”的粗暴结论，而应用于判断：

1. 哪些作品已经足够做研究样板
2. 哪些作品后处理优先级更高
3. 哪些模型路线更适合继续作为底座
4. 哪些长篇已经不适合直接依赖整图浏览

## 当前推荐的使用方式

- 把本表作为 corpus 级导航页
- 具体作品仍以对应 `report.md`、`audit.graph.md`、`graph.normalized.json` 为准
- 跨作品研究时优先看：
  - 核心实体覆盖
  - 孤点率与最大连通分量
  - 关系退化率
  - token 成本是否值得重跑
