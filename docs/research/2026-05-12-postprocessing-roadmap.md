# 金庸全集后处理实施清单

本文档不是抽象讨论，而是“全集基础图谱已经跑完之后，下一阶段该怎么做”的实际清单。目标是把当前图谱从“高召回底座”推进到“可研究、可验证、可复用”的 corpus 级资产。

## 当前判断

当前最值得投入的工作，不再是继续批量跑更多金庸作品，而是做后处理。

原因：

- corpus 覆盖已经够了
- 主要问题已从“有没有图”转成“图怎么整理”
- 再继续重复同类 index，边际收益明显下降

## 后处理总目标

1. 降低明显噪声与污染
2. 合并高价值别名和重复实体
3. 收敛关系类型，减少复合边
4. 建立面向研究问题的主题视图
5. 为跨作品研究建立可迭代实体层

## 第一阶段：全集级清理

### 目标

先做“低风险、高收益”的清理，不直接修改单书原始图谱，而是在后处理层建立统一结果。

### 工作项

1. 建立全集元数据索引
   - 汇总每部作品的 `report.json`、`audit.graph.json`、`graph.normalized.json`
   - 形成统一目录和统计入口

2. 标记明显异常实体
   - 跨作品污染实体
   - 明显无语义价值的噪声节点
   - 英文类型或异常类型残留

3. 标记低价值泛关系
   - `关联` 及等价泛关系
   - 过于抽象但证据薄弱的复合关系

4. 建立“保留 / 审查 / 剪枝”三分类
   - `保留`：核心人物、组织、地点、武功、宝物、事件
   - `审查`：边缘人物、泛群体、描述模糊节点
   - `剪枝`：明显噪声节点或跨作品污染节点

### 产物建议

- `runs/jinyong/_global/scorecard.json`
- `runs/jinyong/_global/noise_candidates.json`
- `runs/jinyong/_global/relation_cleanup_candidates.json`

## 第二阶段：高价值实体对齐

### 原则

- 不修改单书原始图谱
- 新建跨作品实体层
- 对齐必须保留证据和来源

### 优先对齐对象

1. 人物
   - 主角、主要配角、跨作品复用人物、称号人物

2. 组织与门派
   - 少林、武当、丐帮、红花会、天地会、日月神教等

3. 地点
   - 少林寺 / 少林派 / 少林僧人需区分实体与群体
   - 武当山 / 武当派等也需要规则化

4. 武功、秘籍、兵器、宝物
   - 这是金庸 corpus 很有研究价值的一层

### 对齐方法

1. 同名候选
2. 别名候选
3. 描述相似候选
4. 邻居相似候选
5. 续作 / 强关联作品优先候选

### 结果类型

- `same_entity`
- `related_entity`
- `different_entity`

### 产物建议

- `runs/jinyong/_global/global_entities.json`
- `runs/jinyong/_global/alignment_candidates.json`
- `runs/jinyong/_global/alignment_decisions.json`

## 第三阶段：关系归一

### 目标

减少“大包边”和标签漂移，让后续 query、路径分析和跨作品比较更可靠。

### 工作项

1. 识别高频泛关系
2. 识别同义关系标签
3. 标记复合关系描述
4. 为关键关系建立归一规则

### 第一批建议优先收敛的关系

- 师徒
- 所属
- 敌对
- 情感
- 影响
- 使用
- 传授

### 注意

关系归一不能只看标签，还要看证据描述。  
不要为了“统一好看”把不同语义硬合并。

### 产物建议

- `runs/jinyong/_global/relation_mapping.json`
- `runs/jinyong/_global/compound_relation_candidates.json`

## 第四阶段：研究视图

### 目标

停止把整图当主界面，转向面向问题的视图。

### 建议优先做的研究视图

1. 人物关系子图
2. 门派 / 组织子图
3. 武功传承子图
4. 宝物与冲突子图
5. 地点迁移子图
6. 跨作品共享实体视图

### 为什么这一步重要

整图太大，视觉上已经不适合作为研究主入口。  
真正可用的是：

- 子图
- 主题视图
- 问题驱动的 query

### 产物建议

- `runs/jinyong/_global/views/`
- `runs/jinyong/_global/subgraphs/`

## 第五阶段：问题验证

### 目标

不再抽象谈“金庸宇宙”，而是用具体问题验证图谱是否真的有研究价值。

### 推荐优先验证的问题

1. 主角地点迁移与关系网络如何共同变化
2. 门派与权力结构在不同作品中如何重复出现
3. 武功、秘籍、宝物如何驱动冲突与人物命运
4. 跨作品共享实体是否真能支撑字典型查询
5. 传统 NLP baseline 与图谱方法相比，在哪些问题上真正提升了结果质量

### 验证方式

- 每个问题都要保留证据链
- 先做人可审查的小样本
- 不追求第一步就自动生成“论文级结论”

## 当前优先级建议

### 最高优先级

1. 全集总表
2. 全集噪声与污染候选清单
3. 全局实体对齐层原型

### 次高优先级

1. 关系归一规则
2. 主题视图与子图工作流
3. 2-3 个研究问题的实证验证

### 暂缓

1. 全量重跑全部作品
2. 立刻引入重型图数据库
3. 对所有细枝末节做人工精修

## 交接提醒

后续接手者要记住两条硬边界：

1. 不把单书原始图谱直接当终版知识库  
2. 不在没有明确研究问题的前提下，空泛追求“金庸宇宙全自动联动”

当前最有价值的路线，是围绕明确问题，在 corpus 底座上逐层做清理、对齐、裁剪和视图构建。
