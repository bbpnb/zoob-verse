# 《笑傲江湖》高级查询模板

本文记录基于《笑傲江湖》长篇图谱实测得到的 query 经验。目标不是给出“最文学”的题目，而是沉淀一批 **高级但可检索** 的问题模板，作为后续长篇作品查询设计的基线。

## 结论

《笑傲江湖》这类长篇图谱已经可以支持中高阶问题，但题面必须满足四个条件：

1. 有明确人物或组织锚点
2. 有明确的关系或因果方向
3. 有明确阶段或节点要求
4. 有明确输出结构

反之，如果问题太抽象，当前 query 很容易拒答。

## 本次实测

### 跑通的题型

#### 1. 人物权力伪装链

问题：

> 岳不群是如何从“君子剑”形象一步步暴露真实权力意图的？请按早期伪装、中期布局、后期摊牌三段说明，并指出他对令狐冲、林平之、五岳并派分别造成了什么影响。

为什么有效：

- 有明确核心人物：岳不群
- 有明确分析轴：伪装 -> 布局 -> 摊牌
- 有明确影响对象：令狐冲、林平之、五岳并派
- 模型不需要自己决定“该从哪里讲起”

#### 2. 人物位置变化链

问题：

> 令狐冲与任盈盈的关系，如何改变了他在华山派、恒山派、日月神教之间的位置？请按事件顺序列出3到5个关键节点，并说明每一步他失去了什么、获得了什么。

为什么有效：

- 有明确人物：令狐冲、任盈盈
- 有明确组织：华山派、恒山派、日月神教
- 有明确输出格式：3 到 5 个节点、每一步的得失
- 适合图谱做“人物 - 组织 - 事件”联合检索

### 没跑通的题型

#### 1. 过于抽象的“最关键主链”

例如：

> 梳理《笑傲江湖》中最关键的一条权力伪装与反转链条。

问题在于它要求系统先自己决定：

- 什么叫“最关键”
- 该选哪些人物
- 该舍弃哪些支线
- 该如何定义“反转”

这超出了当前 query 检索层的稳定能力。

#### 2. 过于抽象的“阵营重组”

例如：

> 如果把令狐冲的成长看成一次阵营重组，请分析他如何形成新的联盟网络。

问题在于：

- “阵营重组”是分析者视角，不是文本里的显式实体或关系
- “联盟网络”对当前关键词抽取来说也偏抽象

改写成“与哪些门派/人物的关系发生变化、按节点列出得失”之后，效果明显更好。

## 高级 query 设计原则

### 原则 1：先给人物或组织锚点

坏问法：

- 权力如何腐蚀人？

好问法：

- 岳不群与左冷禅分别如何通过门派秩序争夺权力？

### 原则 2：把抽象概念压成可检索动作

坏问法：

- 最重要的深层动机是什么？

好问法：

- 哪些早期事件影响了林平之后续的复仇选择？请按因果顺序说明。

### 原则 3：要求节点、阶段或顺序

如果没有“阶段/节点/顺序”，模型很容易泛泛而谈。  
有了这个约束，图谱检索和正文证据更容易对齐。

### 原则 4：最好要求“影响对象”或“得失”

这会迫使答案不只讲事件，还要讲结构变化。

## 可复用模板

以下模板可直接迁移到其他长篇作品。

### A. 权力结构题

1. `X 是如何从表面身份一步步暴露真实意图的？请按早期伪装、中期布局、后期摊牌说明。`
2. `围绕 X、Y、Z，梳理一条最清晰的权谋因果链。要求列出关键事件、利用关系和格局变化。`

### B. 人物位置变化题

1. `X 与 Y 的关系，如何改变了 X 在 A、B、C 三个组织之间的位置？请按事件顺序列出 3 到 5 个节点。`
2. `把 X 的成长看成身份转移过程，请说明每一步失去了什么、获得了什么。`

### C. 物件驱动题

1. `某件物件如何串起不同人物之间的冲突与合作？请按流转顺序说明。`
2. `某件秘籍/宝物对不同人物分别意味着什么？它如何改变各自选择？`

### D. 门派与秩序题

1. `A 门派与 B 门派在本书中分别承担什么秩序功能？请通过关键人物和事件说明。`
2. `某次并派/分裂/联盟，如何改变了作品中的权力分布？`

### E. 情感与价值选择题

1. `X 与 Y 的情感关系如何影响了 X 的道德选择或组织选择？`
2. `X 在哪几个节点上放弃了旧身份，转而接受了新的关系网络？`

## 对后续金庸作品的意义

《笑傲江湖》的实测说明：

- 长篇 query 可以问“高级题”，但必须做题面工程。
- 图谱最擅长的是“结构化人物线、组织线、因果线”，而不是无边界的文学大题。
- 未来其他长篇，如《天龙八部》《神雕侠侣》《射雕英雄传》，都应先用这套模板出一批可检索问题，再做跨作品对照。

## 与图谱目标的关系

这批模板的意义，不只是提高回答成功率，更是为了验证图谱是否真的在做下面几件事：

1. 先找作品内部证据，而不是让模型裸答。
2. 把长篇叙事压成“可检索的结构问题”。
3. 为后续跨作品比较准备统一问题框架。

如果一条题目必须完全依赖模型自由发挥才能回答，那就不属于当前图谱 query 的强项。
